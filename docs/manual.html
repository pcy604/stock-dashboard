운용 루틴

주기별 점검 항목
운용 루틴정기 점검 · 수시 점검
일간 · 장 마감 후
보유 종목 손절 점검
  1. 🏠 종합 — 당일 시황 리포트(한국 15:50 · 미국 익일 06:30)
  2. 🛡️ 내 포트폴리오 — 손절가(보유 중 고점 대비 −20%) 도달 종목
  3. 고점 갱신 종목은 손절가 상향
  4. 도달 종목은 규칙상 매도 대상
주간 · 토요일
다음 주 매매 계획
  1. 🏠 종합 — 지수 게이트(주봉 5주선) · 하회 시 신규 진입 중지
  2. 보유 종목 RS 70 미만 → 다음 거래일 매도
  3. 🧭 종목 발굴 — 빈 자리만큼 매수 대상(RS 순, 최대 10종)
  4. 추가 매수 조건 — 첫 매수가 대비 +10% · +20%
분기 · 실적 시즌
후보군 변동 점검
  1. 보유 종목 실적 발표일 확인
  2. 흑자전환 판정 변경 → 다음 토요일 후보에 자동 반영
  3. 🧭 종목 발굴 — 후보 편입·탈락 확인
  4. 규칙 변경은 백테스트 검증 후에만
수시 · 필요 시
종목 실사 · 국면 해석
  1. 🔍 종목 분석 — 결론 · 실전 규칙 대조 · 투자 논리 훼손 조건
  2. 펀더멘탈 · 히스토리 · 수급 근거 확인
  3. 🌍 매크로 — 유동성 · 경기 국면 해석(참고 · 매매 규칙 미반영)
  4. 국면 전환은 주간 지수 게이트가 매매에 반영
