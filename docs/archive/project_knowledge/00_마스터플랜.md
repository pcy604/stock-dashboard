## 7. 수익화 · 글로벌화 관점

- **팔 수 있는 것은 '신호'가 아니라 '규율'이다.**
  - 이 프로젝트의 차별점은 실패를 기록하는 원장과, 규칙을 기계가 강제하는 구조다. 종목 추천은 경쟁이 과열된 시장이다.
  - 한국에서 유료 종목 추천은 유사투자자문업 신고가 필요하고, 남의 계좌를 굴리는 것은 투자일임업 인가가 필요하다. 규제를 피하려면 **"각자 자기 규칙을 백테스트하고 자동 집행하는 도구"** 형태가 현실적이다.
- **확장 경로 후보**:
  1. 빌드로그 콘텐츠: 실패 기록 자체가 콘텐츠 (SNS 기록 프로젝트와 연결)
  2. 규칙 백테스트·채점 SaaS: 사용자가 규칙을 넣으면 순서 편향·생존편향·연도 분산까지 정직하게 채점
  3. 토스·KIS·IBKR 등 증권사 API 공통 실행기를 오픈소스로 공개
- **현실 점검**: buza-bot의 외부 사용자는 0명이다(2026-08 실측). 수익화보다 **본인 계좌에서 12개월 실전 기록**이 먼저다. 그 기록이 없으면 무엇을 팔든 근거가 없다.
