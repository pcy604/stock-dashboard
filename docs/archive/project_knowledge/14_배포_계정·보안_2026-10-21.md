# 14. 배포 준비 — 계정·보안·저장 (2026-10-21)

## 결정
- 토스 자동매매 서비스 연계 **보류**. 본인 전용 / 상용화(법률 검토 후) 트랙을 나중에 분리.
- 수익화: **무료로 사용자 모은 뒤** DAU/WAU/MAU가 기준을 넘으면 구독·광고·매각 검토. 측정은 첫날부터.
- 지인 테스트 → 구글 로그인 + `open = true`(로그인한 누구나 입장, `blocked_emails`로 차단).
- DB는 새 프로젝트 대신 **기존 Supabase BUZA_ALARM 프로젝트에 같이** — 봇이 이미 users·subscriptions·analyses·deliveries·bot_state를 쓰고 있음(삭제 금지). 대시보드 계정 ↔ 봇 chat_id 연결을 같은 DB에서 하기 위함.

## 운영 설정 위치
- Streamlit Secrets: https://share.streamlit.io/ → 앱 ⋮ → Settings → Secrets (`[auth]` `[access]` `[store]` `[analytics]`, 양식은 `.streamlit/secrets.toml.example`)
- Google OAuth: life quest와 **같은 Cloud 프로젝트**, 이미 프로덕션 게시 상태 — "테스트로 돌아가기" 누르지 말 것. 상용화 때 전용 프로젝트로 분리.
- master_key는 바꾸면 기존 저장분 복호화 불가.

## 정정 기록
- 처음에 "토스 잔고가 공개 노출됐다"고 판단했으나 오판 — pf_vault.py로 암호화(PBKDF2 39만 회)된 파일이었고 비밀번호 입력 시에만 보임. 단 저장소가 public이라 비밀번호 강도가 유일한 방어선.
