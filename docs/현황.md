## 🔬 주도주 사후분석 v3.1 (설계 — 차니)

**4개 축 (전 종목 매 분기 부여 → 기저율 확보)**

| 축 | 값 | 판정(그 시점 정보만) |
|---|---|---|
| ① 단위 | 업종 주도 / 업종 내 대장 / 단독 주도 | 업종 RS 상위 + 업종 내 52주 신고가 비율(폭) · 종목 RS 의 업종 내 순위 |
| ② 동인 (다모다란) | 내러티브 / 넘버스 | ln(주가 변화) = ln(이익 변화) + ln(PER 변화), 적자 = 매출 × PSR. 멀티플 기여 > 50% = 내러티브 (종목분석 탭 분해 재사용) |
| ③ 유형 6 | L1 턴어라운드·흑자전환 · L2 사이클 업턴 · L3 이익 가속 성장 · L4 내러티브 선행 · L5 적자 성장 · L6 자산·구조 변화 | v2 판정 규칙 |
| ④ 국면 | 점화(멀티플 확장) · 확인(이익이 따라옴) · 성숙(성장 둔화·멀티플 축소) · 붕괴 | 순서 고정 아님 → **상태 그래프.** 어느 국면에서든 붕괴 직행 가능, 성숙 없이 장기 지속 가능. 유형별 국면 전이 확률 표가 산출물 |

**변천사 추적**: 종목별 분기 상태(단위·동인·유형·국면) 시계열 → `results/leader_states.parquet`.
**가설**: 최고 진입 구간 = 내러티브 → 넘버스 전환 · 청산 = 넘버스가 내러티브를 더는 확인 못 함 → #22 후보 팩터.

**🧨 고점 해부 모듈**
- 전제: 시장은 이익의 2차 미분에 가격을 매김 → 고점 예측이 아니라 '확인 후 대응' 설계.
- 측정: 과거 주도주마다 5개 고점 날짜 — ① 주가 ② 이익 성장률(2차 미분 = 0) ③ 이익 수준 ④ PER ⑤ 언급량(#23) — 유형별로 주가 고점 대비 몇 주 앞/뒤인지 분포.
- 활용 원칙(검증 대상): 1) 가격이 숫자보다 먼저 말함(33주 신고가 미갱신 매도 계열) 2) 2차 미분은 비중 조절(1/3 트림 → 분할 청산) 3) 언급량 폭증 초기 = 진입, 극단 = 4국면 4) 사이클주(L2) 별도 — 저PER 이 고점 신호.
- 판정: 앞서는 신호가 유형별로 있으면 유형별 매도 규칙 후보, 없으면 '가격 추세 청산이 유일한 답' 기록.

**분석 절차**: 탐색 2015~2020(시험 수 기록) → 확인 2021~2026(기준 고정, 1회) · 4단계(필요성·선행성·충분성·실전성) · 점 12 + 궤적 16 · 유형·시장별 표본 30 미만 병합.
**CC 데이터 작업**: 분기별 PER·PSR·이익·매출 시계열(미국 SEC·한국 DART 2016~) → 수익 분해 · 업종 폭 · 상태 테이블 · 언급량 일별(#23).

깨지는 지점을 먼저 박고 테스트로 고정한 것:
- L2 는 오경보 기계가 되기 쉽다(약관 배너가 매주 바뀜) → 원문 해시 대신 **주의어 든 줄만** 비교.
