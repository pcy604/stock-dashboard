### 우리 시스템에 필요한 것
- 원장(`live/trades.jsonl`)에 이미 체결일·가격·수수료가 있다 → **연말에 PIT-38 계산표(원화 → PLN, NBP D-1)** 를 뽑는 스크립트 하나면 된다(백로그).
- ⚑ 차니 확인: ① 2026년분부터 신고 대상(2026-11-09 첫 체결) ② `ulga na powrót`(귀국자 감면)는 근로소득용이라 PIT-38 자본이득엔 해당 없을 가능성이 높음 — 세무사 확인 ③ 한국 귀국 후 거주지가 바뀌는 해의 처리(이중 거주 판정)는 그때 다시.
- 배당: 한국 원천징수 후 폴란드 19%와 차액 정산 구조(조약 세율은 미확인 ⚑).

## 2. 고정 IP 실행기 — 노트북 단일 장애점 해소
토스 Open API 는 **WTS 설정 → Open API → 허용 IP** 에 등록된 IP 에서만 호출된다(미등록 = 403). GitHub Actions 러너는 IP 가 매번 바뀌어 못 쓴다.

| 후보 | 비용 | 고정 IP | 메모 |
|---|---|---|---|
| **Oracle Cloud Always Free — AMD Micro(1/8 OCPU·1GB)** | 0원 | 예약 공인 IPv4 1개 무료 | 주 1~2회 봇·하루 몇 번 확인엔 충분. 가용량 문제 거의 없음. 1순위 |
| Oracle Always Free — Ampere A1(Arm) | 0원 | 동일 | 2026 들어 무료 할당이 2 OCPU/12GB 로 줄었다는 보고 · 서울/춘천은 용량 부족 잦음 |
| 소형 유료 VPS(Lightsail·Vultr 등) | 월 3~5달러 | 포함 | 가장 덜 번거로움 |

### 옮길 때 순서(차니 작업 ≈ 30분)
1. https://www.oracle.com/cloud/free/ 가입(카드 본인 확인, 홈 리전은 바꿀 수 없음 — 가용량 여유 있는 리전 아무 곳).
2. Compute → Create instance → Shape `VM.Standard.E2.1.Micro`(Always Free) · Ubuntu 24.04 · 공인 IP **예약(Reserved)** 으로 붙이기.
3. 토스 WTS → 설정 → Open API → 허용 IP 에 그 IP 추가(노트북 IP 는 당분간 같이 둔다).
4. 서버에서 `git clone` → `.env` 에 토스 키·텔레그램 → `crontab` 으로 노트북과 같은 시각(KST 08:40·09:10 등) `python live/bot.py` — 이 단계는 Claude 가 스크립트로 만들어 줄 수 있다.
5. 1주 동안 노트북·서버 둘 다 **모의**로 돌려 같은 판단인지 대조 → 서버만 실전으로 전환.
