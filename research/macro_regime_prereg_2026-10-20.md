# 욕심 조절 신호 사전 등록 — 결과 보기 전 (2026-10-20)

### 2-5. 욕심 조절 신호 — 매크로 리스크 온/오프 (2026-10-20 사전 등록, 결과 보기 전)
가설: 경기·신용·유동성 신호가 나빠질 때 주식 노출을 줄이면, 200일선 스위치만 쓸 때보다 계좌 MDD가 더 줄어든다.

| 항목 | 정의 (고정) |
|---|---|
| 대상 | S&P500 총수익(^SP500TR), 주봉 금요일 종가. 현금은 3개월 국채(DTB3) 이자 |
| 기간 | 1988-01 ~ 2026-09 (구간 A 1988~2007 · B 2008~2019 · C 2020~2026) |
| 지연 | 신호 다음 주 집행(1주) · 월간 지표는 발표 시차 1개월 · 주간 지표 1주 |
| 비용 | 노출 변경분 × 0.1% |
| 기준 B0 | 매수보유 100% |
| 기준 B1 | **200일선 스위치**: 금요일 종가가 200일 이평 위 → 100%, 아래 → 0% (40주 이평과의 차이도 함께 보고) |
| 후보 신호 (경고=1) | C1 신용: Baa−10년물 스프레드 13주 변화 ≥ +0.30%p · C2 NFCI > 0 · C3 실업수당 4주평균이 52주 최저 대비 +15% 이상 · C4 삼의 법칙 ≥ 0.5 · C5 10Y−3M < 0 · C6 우라가미 역금융·역실적 국면 · C7 막스 시계추 ≥ 80(탐욕) · C8 강달러(DXY 200일선 위 & 13주 상승) · C9 합성: C1~C4 경고 개수 k → 노출 × (1 − 0.25k) |
| 적용 방식 | (a) 단독: 경고 시 노출 50% · (b) B1 위에 덧씌움: 노출 = B1 × (경고 시 0.5) |
| 주변값 | C1 ±0.1%p·8/26주 · C2 −0.2/+0.2 · C3 10/20% · C4 0.4/0.6 · C7 70/90 |

- **합격(욕심 게이지 채택)**: ① (b)의 Calmar(CAGR÷|MDD|)가 B1보다 0.05 이상 높고 MDD가 B1보다 나쁘지 않다 ② 세 구간 중 2개 이상에서 (b) Calmar ≥ B1, 어느 구간도 CAGR −2%p 초과 손실 없음 ③ 주변값 과반에서 같은 결론
- **참고 신호(화면 ✅, 비중 미사용)**: (a)가 B0 대비 MDD 5%p 이상 개선 + Calmar 상승 + 위 ②·③
- 한계(미리 적어둠): 지수 대상 검증이다. 위성(이익가속 20칸)에 덧씌운 효과는 v13y 데이터로 따로 잰다. 1988년 이후 하락장 5번(1990·2000·2008·2020·2022)뿐이다.
